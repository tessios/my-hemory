# 아이폰에서 쓰기 (Apple Developer 계정 없이)

앱스토어·개발자 계정 없이 **Safari → 홈 화면에 추가** 만으로 네이티브 앱처럼 씁니다.

## 1. 홈 화면에 추가

1. iPhone **Safari** 에서 <https://tessios.github.io/my-hemory/> 열기 (Chrome·인스타 인앱 브라우저는 안 됨)
2. 하단 **공유(⬆️)** → **홈 화면에 추가** → 이름 `Hemory` → 추가
3. 홈 화면 아이콘으로 실행하면 주소창·탭바 없이 전체 화면으로 열립니다
   - `apple-mobile-web-app-capable`, `apple-mobile-web-app-title`, `apple-touch-icon`(180px), `manifest.webmanifest`(standalone) 모두 설정되어 있습니다
   - 상태바는 흰 배경에 맞춘 `default` 스타일, 세이프 에어리어(`env(safe-area-inset-*)`) 대응

> 홈 화면 앱과 Safari 탭은 저장 공간이 분리됩니다. **처음 설정(Client ID)과 로그인은 홈 화면 앱에서** 하세요.

## 2. 녹음 — 두 가지 경로

### A. 짧은 메모 (앱 안에서 바로)
- 앱 오른쪽 아래 **🎙 버튼** → 시작 → (필요하면 일시정지) → 정지 → 제목·유형 선택 → **드라이브에 저장**
- 저장 즉시 `Hemory-개인녹음/` 에 올라가고, Gemini 키가 있으면 **폰에서 바로 전사**됩니다. 키가 없으면 `_inbox` 에 들어가 맥이 처리합니다.
- 파일 가져오기 버튼으로 아이폰 **파일** 앱에 있는 오디오를 올릴 수도 있습니다.

#### 녹음 중 화면 꺼짐 방지 (Wake Lock)
- 녹음을 시작하면 브라우저가 **화면 잠금(Wake Lock)** 을 걸어, 화면이 저절로 꺼지지 않습니다. iOS **Safari 16.4 이상**에서 동작하고, 켜져 있으면 녹음 시트에 `화면 꺼짐 방지 켜짐` 배지가 보입니다.
- 화면이 다시 보일 때(다른 앱에서 돌아오기 등) 자동으로 잠금을 다시 겁니다.
- **한계(정직하게):** 직접 측면 버튼으로 화면을 잠그거나, 전화가 오거나, 다른 앱으로 전환하면 iOS가 마이크를 끊습니다. 배터리 절약을 위해 화면 밝기를 낮추고, 충전기에 꽂아 둔 채 쓰는 편이 안전합니다.

#### 침묵 구간 자동 건너뛰기 (VAD, 기본 켜짐)
- 녹음 시트의 **침묵 구간 자동 건너뛰기** 토글(기본 ON). 켜면 마이크 레벨(RMS)을 40ms마다 재서, 말이 없을 때는 소리를 담지 않고(게인 0) 말이 시작되면 바로 다시 담기 시작합니다. 말끝이 잘리지 않도록 0.7초 여운을 둡니다.
- 배지의 `VAD · 말한 구간 1:12` 로 실제로 말한 시간을 볼 수 있고, 저장 화면에도 `말한 구간 / 전체`가 나옵니다.
- 주변 소음(에어컨·도로)은 침묵 동안 학습해서 임계값을 스스로 맞춥니다.
- **한계:** 웹 녹음 API로는 파일 길이 자체를 줄일 수 없습니다. 침묵은 `무음`으로 들어가고, 전사 단계에서 맥 파이프라인의 VAD 가 그 구간을 실제로 건너뜁니다. 몇 시간짜리 종일 녹음은 파일이 커질 수 있으니 아래 B 경로가 안전합니다.

#### 뒤집어서 자동 녹음 (Face-Down, 선택)
- 녹음 시트의 **뒤집어서 자동 녹음** 토글을 켜면, 폰을 책상에 엎어 둔 채(β > 145°) **1.5초**가 지나면 자동으로 녹음이 시작되고 화면을 **검은색 절전 오버레이**로 덮습니다(작은 `녹음 중 · 00:12` 표시만 희미하게).
- 다시 들면(`|β| < 130`) 그 자리에서 **자동 저장**합니다. 오버레이를 탭해도 종료·저장됩니다.
- 처음 켤 때 동작·방향 접근 허용을 한 번 물어봅니다(거부하면 설정 → Safari → 동작 및 방향 접근에서 허용).
- 앱을 다시 열어 첫 화면을 한 번 탭하면 권한이 다시 연결됩니다.

#### 예약 녹음 (요일·시간)
- 설정 탭 → **예약 녹음** → 모드를 켜고, 월~일 각각 켜고 끄면서 시작~종료 시간(예: 평일 09:00~18:00)을 정합니다. 자정을 넘기는 구간(22:00~06:00)도 됩니다.
- 앱이 열려 있을 때 그 시간대가 되면 **자동으로 녹음을 시작**하고, 종료 시각에 멈춰 **드라이브 `_inbox`로 자동 저장**합니다. 화면 아래 검은 배너에 `예약 녹음 중 · 말한 구간`이 보이고, 배너의 **종료**를 누르면 바로 저장합니다.
- iOS는 사용자 조작 없이 마이크를 막는 경우가 있습니다. 자동 시작이 막히면 화면을 한 번 탭하면 다시 시도합니다.
- 전사 유형(회의·업무·일상…)은 설정에서 미리 골라 둡니다.

#### 녹음 유실 방지(화면이 가려질 때 즉시 저장)
- 녹음 중 다른 앱으로 넘어가거나 화면이 잠겨 `visibilitychange`·`pagehide` 가 오면, 그때까지 모인 오디오를 **기기 큐(IndexedDB)에 먼저 보관**하고 드라이브 업로드를 시도합니다. 연결이 끊겼으면 다음 연결 때 자동으로 다시 올립니다.

### B. 긴 회의·강의 — 아이폰 음성 메모 (화면이 꺼져도 계속)
1. **음성 메모** 앱으로 녹음 (화면 잠금 상태에서도 계속 녹음됨)
2. 녹음 목록에서 항목 → **공유(⬆️)** → **Google 드라이브**
3. 저장 위치로 **Hemory-개인녹음 → `_inbox`** 선택 → 저장
   - Google 드라이브 앱이 설치되어 있어야 공유 시트에 나타납니다
   - 파일명은 그대로여도 되고, `20261124-1430_meeting_현장` 처럼 바꿔도 됩니다(시각·유형 자동 인식)
4. 맥이 다음 실행 때 `_inbox` 를 비우며 전사·요약해 `YYYY-MM/` 폴더로 옮깁니다
5. 앱에서 **동기화(↻)** 또는 앱을 다시 열면 전사문·요약이 나타납니다

#### 단축어(Shortcuts)로 한 번에 올리기 (선택)
1. **단축어** 앱 → 새 단축어
2. 액션 추가 → **파일 저장**
   - "서비스 위치"에서 **Google 드라이브** 선택 → 경로 `Hemory-개인녹음/_inbox`
   - 입력은 **단축어 입력**(공유 시트로 받은 파일) 사용
3. 이름: `Hemory에 저장`
4. **음성 메모** 앱에서 녹음 → 공유 → 아래로 스크롤 → `Hemory에 저장`
5. (선택) 홈 화면에 단축어 아이콘을 두면 두 번 탭으로 업로드됩니다

> 자동화(개인 자동화)는 iOS가 "음성 메모" 앱 이벤트를 제공하지 않아 트리거로 쓸 수 없습니다. 공유 시트 단축어가 가장 안정적입니다.

#### 특정 요일·시간에 자동 알림/음성 메모 열기
1. **단축어** 앱 → 하단 **자동화** → **+** → **특정 시간**
2. 시간(예: 09:00)과 반복(매일 또는 요일 선택)
3. 동작: **알림 표시** 또는 **앱 열기 → 음성 메모**(바로 녹음 화면)
4. **실행 전 확인**을 끄면 잠금 해제 없이도 동작합니다
5. 이 앱으로 받고 싶으면 자동화의 앱 열기를 **Hemory 홈 화면 앱**으로 바꾸고, 앱의 **예약 녹음**을 켜 두세요

> 앱 안의 같은 가이드는 **설정 → 아이폰 단축어 가이드 보기** 에서도 볼 수 있습니다.

#### 동작 버튼(Action Button)에 음성 메모 달기
1. **설정 → 동작 버튼** → 옆으로 넘겨 **음성 메모** 선택 (iPhone 15 Pro 계열)
2. 버튼을 길게 누르면 음성 메모가 바로 열려 녹음할 수 있습니다
3. 음성 메모 대신 **단축어**를 골라 위 `Hemory에 저장` 단축어를 연결해도 됩니다

## 3. 검색

- 하단 **검색** 탭 → 검색어 입력. 띄어쓰기가 달라도 찾습니다(정규화 인덱스).
- 결과는 **문장 단위**로 나오고, 검색어가 검정 하이라이트로 표시됩니다. 날짜·화자·녹음 제목이 함께 보입니다.
- 문장을 누르면 상세로 넘어가 **그 지점부터 재생**(+15초/−15초, 0.8~1.5배속).
- **AI에게 묻기** 탭: "지난 회의에서 결정된 게 뭐야?" 처럼 물으면 근거 문장을 모아 Gemini가 답합니다(키 필요). 키가 없으면 근거 문장만 보여 줍니다.

## 4. 검색이 안 될 때

| 증상 | 확인 |
|---|---|
| 기록이 0건 | 설정 → **지금 동기화**. 드라이브 `Hemory-개인녹음` 에 `*.json` 이 있는지 확인 |
| "전사 대기"만 보임 | 맥 파이프라인이 아직 안 돌았거나 실패 → 맥에서 `~/Library/Logs/hemory-pipeline.log` 확인 |
| 재생이 안 됨 | 오디오 파일이 `_inbox`/월 폴더에 있는지, 로그인이 살아 있는지(설정 → Google 연결) |
| 앱이 흰 화면 | 서비스 워커 캐시 문제. 설정 → 이 기기 캐시 비우기, 또는 앱 삭제 후 다시 추가 |

## 5. 배터리·데이터

- 앱은 화면을 열 때만 동기화합니다(백그라운드 폴링 없음).
- 오디오는 재생할 때만 드라이브에서 스트리밍하고, 전사 JSON만 기기에 캐시합니다(1년 보관이므로 수백 KB~수 MB 수준).
