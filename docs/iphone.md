# 아이폰에서 쓰기 (Apple Developer 계정 없이)

앱스토어·개발자 계정 없이 **Safari → 홈 화면에 추가** 만으로 네이티브 앱처럼 씁니다.

## 1. 홈 화면에 추가

1. iPhone **Safari** 에서 <https://tessios.github.io/my-hemory/> 열기 (Chrome·인스타 인앱 브라우저는 안 됨)
2. 하단 **공유(⬆️)** → **홈 화면에 추가** → 이름 `Hemory` → 추가
3. 홈 화면 아이콘으로 실행하면 주소창·탭바 없이 전체 화면으로 열립니다
   - `apple-mobile-web-app-capable`, `apple-mobile-web-app-title`, `apple-touch-icon`(180px), `manifest.webmanifest`(standalone) 모두 설정되어 있습니다
   - 상태바는 흰 배경에 맞춘 `default` 스타일, 세이프 에어리어(`env(safe-area-inset-*)`) 대응

> 홈 화면 앱과 Safari 탭은 저장 공간이 분리됩니다. **처음 설정(Client ID)과 로그인은 홈 화면 앱에서** 하세요.

## 2. 녹음 — 두 가지 경로

### A. 짧은 메모 (앱 안에서 바로)
- 앱 오른쪽 아래 **🎙 버튼** → 시작 → (필요하면 일시정지) → 정지 → 제목·유형 선택 → **드라이브에 저장**
- 저장 즉시 `Hemory-개인녹음/` 에 올라가고, Gemini 키가 있으면 **폰에서 바로 전사**됩니다. 키가 없으면 `_inbox` 에 들어가 맥이 처리합니다.
- 파일 가져오기 버튼으로 아이폰 **파일** 앱에 있는 오디오를 올릴 수도 있습니다.

**한계(정직하게):** iOS는 Safari가 백그라운드로 가면(화면 잠금, 전화 수신, 다른 앱 전환) 마이크를 끊습니다. 그래서 긴 회의는 B 경로를 권합니다.

### B. 긴 회의·강의 — 아이폰 음성 메모 (화면이 꺼져도 계속)
1. **음성 메모** 앱으로 녹음 (화면 잠금 상태에서도 계속 녹음됨)
2. 녹음 목록에서 항목 → **공유(⬆️)** → **Google 드라이브**
3. 저장 위치로 **Hemory-개인녹음 → `_inbox`** 선택 → 저장
   - Google 드라이브 앱이 설치되어 있어야 공유 시트에 나타납니다
   - 파일명은 그대로여도 되고, `20261124-1430_meeting_현장` 처럼 바꿔도 됩니다(시각·유형 자동 인식)
4. 맥이 다음 실행 때 `_inbox` 를 비우며 전사·요약해 `YYYY-MM/` 폴더로 옮깁니다
5. 앱에서 **동기화(↻)** 또는 앱을 다시 열면 전사문·요약이 나타납니다

#### 단축어(Shortcuts)로 한 번에 올리기 (선택)
1. **단축어** 앱 → 새 단축어
2. 액션 추가 → **파일 저장**
   - "서비스 위치"에서 **Google 드라이브** 선택 → 경로 `Hemory-개인녹음/_inbox`
   - 입력은 **단축어 입력**(공유 시트로 받은 파일) 사용
3. 이름: `Hemory에 저장`
4. **음성 메모** 앱에서 녹음 → 공유 → 아래로 스크롤 → `Hemory에 저장`
5. (선택) 홈 화면에 단축어 아이콘을 두면 두 번 탭으로 업로드됩니다

> 자동화(개인 자동화)는 iOS가 "음성 메모" 앱 이벤트를 제공하지 않아 트리거로 쓸 수 없습니다. 공유 시트 단축어가 가장 안정적입니다.

## 3. 검색

- 하단 **검색** 탭 → 검색어 입력. 띄어쓰기가 달라도 찾습니다(정규화 인덱스).
- 결과는 **문장 단위**로 나오고, 검색어가 검정 하이라이트로 표시됩니다. 날짜·화자·녹음 제목이 함께 보입니다.
- 문장을 누르면 상세로 넘어가 **그 지점부터 재생**(+15초/−15초, 0.8~1.5배속).
- **AI에게 묻기** 탭: "지난 회의에서 결정된 게 뭐야?" 처럼 물으면 근거 문장을 모아 Gemini가 답합니다(키 필요). 키가 없으면 근거 문장만 보여 줍니다.

## 4. 검색이 안 될 때

| 증상 | 확인 |
|---|---|
| 기록이 0건 | 설정 → **지금 동기화**. 드라이브 `Hemory-개인녹음` 에 `*.json` 이 있는지 확인 |
| "전사 대기"만 보임 | 맥 파이프라인이 아직 안 돌았거나 실패 → 맥에서 `~/Library/Logs/hemory-pipeline.log` 확인 |
| 재생이 안 됨 | 오디오 파일이 `_inbox`/월 폴더에 있는지, 로그인이 살아 있는지(설정 → Google 연결) |
| 앱이 흰 화면 | 서비스 워커 캐시 문제. 설정 → 이 기기 캐시 비우기, 또는 앱 삭제 후 다시 추가 |

## 5. 배터리·데이터

- 앱은 화면을 열 때만 동기화합니다(백그라운드 폴링 없음).
- 오디오는 재생할 때만 드라이브에서 스트리밍하고, 전사 JSON만 기기에 캐시합니다(1년 보관이므로 수백 KB~수 MB 수준).
